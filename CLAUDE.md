# Cluck Strike

Browser crash game: React 19 + Vite, Feature-Sliced Design, deployed from `main` to https://cluck-strike.vercel.app/.

- **Product and decisions:** `docs/spec.md`, `docs/adr/`, and `GLOSSARY.md` (its terms name code and UI text).
- **Work items:** `docs/agents/issue-tracker.md`: tickets are local Markdown files, and how a ticket is closed.
- **Running, verifying, committing:** `docs/agents/dev-notes.md`, before you run the game, take screenshots, test on a phone layout, or commit and push.
- **Review rules:** `CODING_STANDARDS.md`.
